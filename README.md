# 🚇 Autonomous Subway 3D Lidar Vision (Digital Twin ADAS)

**Интеллектуальная программная система реального времени на базе методов обработки 3D-лидарных данных для мониторинга пространства перед движущимся беспилотным поездом метрополитена и предотвращения столкновений.**

---

## 🌟 Особенности и Нестандартный подход (ВАУ-эффект)

Проект реализует полноценную концепцию **Цифрового Двойника (Digital Twin)** на основе физических показаний 3D-лидара **Hesai 128**:

1. **Световой ИИ-Щит (Адаптивная плотность)**: Интеллектуальный балансировщик нагрузки `NumPy` разделяет сцену на зоны. Избыточные миллионы точек стен туннеля эффективно сжимаются, защищая CPU/RAM от OOM, а дальний створ путей внутри габаритов вагона защищен на 100% — разреженные лучи от препятствий на расстоянии **до 100–120 метров** доходят до кластеризации в исходном качестве.
2. **Динамический 3D-кокон ROI**: Маска контроля не использует жесткий хардкод высоты и ширины. Она покадрово рассчитывает живую секторную медиану рельсового полотна, автоматически подстраиваясь под уклоны (подъемы/спуски) и вертикальную качку поезда.
3. **Гео-шлюз инфраструктуры**: Система анализирует боковой разлет стен через Якоря одометрии. При въезде на станцию или стрелочные переводы (когда хотя бы одна стена улетает дальше заданного порога) алгоритм автоматически сужает створ зрения до чистой колеи, полностью исключая ложные алерты на край платформы.
4. **Интерактивный 3D-Кокпит (Three.js & WebSockets)**: Полноценная Pull-модель («Запрос-Ответ») синхронизирует ИИ-бэкенд с частотой WebGL-рендеринга. В темноте тоннеля Three.js подсвечивает истинную форму преграды (человек, коробка, настил) в виде живого светящегося лазерного облака точек.

## 📂 Архитектура репозитория

```text
├── config.py                 # Глобальный пульт управления чувствительностью, геометрией и ИИ-фильтрами

├── cos_processor_v12.py      # Движок лазерной одометрии стен тоннеля и ОЯР-стрима путей
├── static/                   # Папка со статическими файлами сайта
│   ├── index.html            # Фронтенд (3D-интерфейс кабины машиниста на Three.js / WebGL)
│   └── js/                   # Скрипты библиотек 3D-графики (three.min.js, OrbitControls.min.js)
├── Dockerfile                # Легковесный Docker-образ для развертывания решения жюри
├── quick_check.py            # Единая консольная точка входа: автоматический парсинг, детекция и генерация CSV
├──.gitignore                 # Фильтр репозитория
└── convert_all_bags.py       # Ковертор из скюэль формата в бинарники
```

## 🐳 Инструкция по развертыванию и запуску через Docker

Проект полностью контейнеризирован на базе официального образа **ROS 2 Humble Perception**. Все вычисления и алгоритмы оптимизированы под векторизацию средствами `NumPy` и `DBSCAN`, что гарантирует выполнение расчетов в режиме реального времени на CPU хост-машины без жесткой зависимости от тяжеловесных ML-фреймворков и CUDA.

### 1. Сборка Docker-образа
Соберите легковесный образ (выполнять в корневом каталоге проекта):
```bash
docker build -t metro_lidar .
```

### 2. Первый запуск и развертывание
Запустите контейнер в интерактивном режиме с монтированием текущей папки проекта (для живого обновления кода) и пробросом порта для Web-интерфейса:
```bash
docker run -it \
  --name metro_container \
  -v $(pwd):/app \
  -p 8000:8000 \
  metro_lidar
```
*Вы автоматически окажетесь внутри терминала контейнера в рабочей директории `/app`.*

### 3. Управление контейнером в процессе работы
Если вы вышли из контейнера или перезагрузили ПК, используйте эти команды для управления:
* **Остановка контейнера:** `docker stop metro_container`
* **Запуск остановленного контейнера:** `docker start metro_container`
* **Вход внутрь запущенного контейнера (в терминал):**
  ```bash
  docker exec -it metro_container bash
  ```

## 🎯 Автономный ИИ-конвейер детекции и генерация ответов (Для жюри)

Программный комплекс оснащен единой консольной точкой входа, которая в автоматическом режиме выполняет полный цикл подготовки данных хакатона: от высокоскоростного парсинга сырых ROS 2 bag-файлов (баз данных SQLite3) до нативной десериализации, ИИ-фильтрации, межкадрового трекинга и экспорта результатов в регламентированном формате.

### 🏃‍♂️ Инструкция по запуску тестирования «в одну кнопку»

Находясь внутри запущенного Docker-контейнера, выполните команду автоматического аудита сценария. Вам достаточно лишь указать путь к директории с исходными багами и имя сценария:

```bash
python3 quick_check.py --data_dir /app/for_hackathon --scenario doubleT_obstacle
```

**Что произойдет автоматически:**
1. **Нативный парсер & Конвертер**: Скрипт автоматически определит топик `PointCloud2`, десериализует сообщения из формата CDR, очистит облака точек от шумов/NaN и сохранит их в бинарный кэш `.bin`.
2. **ИИ-Фильтрация & Трекинг v2**: Запустится конвейер детекции (Световой ИИ-щит, воксельное сжатие, секторный RANSAC путей и MOT-трекер v2) с выводом логов реального времени в консоль.
3. **Экспорт Сабмишена**: В корневой директории проекта сгенерируется валидный файл `submission.csv`, строго соответствующий ТЗ конкурса и стандарту осей REP 103 (X — дальность вперед, Y — влево, Z — вверх).

## 🎮 Инструкция по работе с 3D-Интерфейсом

* **Обзор (OrbitControls)**: Зажмите левую кнопку мыши на 3D-сцене для свободного вращения камеры и осмотра тоннеля под любым углом. Высота взгляда жестко привязана к уровню глаз машиниста (1.6м).
* **Пауза / Старт**: Нажмите клавишу **`Пробел` (Space)** или кликните неоновую кнопку `II ПАУЗА СИСТЕМЫ` в верхнем правом углу. Симуляция и сокет-конвейер мгновенно замрут, позволяя детально изучить форму и лазерный силуэт препятствия со всех сторон. Нажмите повторно для продолжения трипа.
* **Экстренное оповещение**: При обнаружении верифицированного препятствия внутри зоны ROI, интерфейс мгновенно переходит в режим тревоги (**EMERGENCY BRAKE TRIPPED**), а на левом пульте отображается карточка цели с указанием ее точной дистанции, положения и морфологической формы.

## 🎛️ Глобальный пульт управления (Гибкость через `config.py`)

Настройка чувствительности ИИ-ядра и визуализации полностью вынесена в `config.py` для защиты Mission-Critical кода от «магических чисел»:

* `V2_OBSTACLE_SHOW_3D_MESHBOX = True` ➔ **Режим ADAS-голограммы**: Отрисовка полупрозрачных 3D-мешей (кубов/цилиндров) поверх лазерных силуэтов преград для визуального контроля габаритов вагона.
* `V2_OBSTACLE_SHOW_3D_MESHBOX = False` ➔ **Киберпанк-режим**: Полигональные коробки полностью отключаются, оставляя на экране Three.js только прецизионное, светящееся неоновое облако точек истинной формы препятствия, исключая перекрытие обзора цветом.
* `V2_OBSTACLE_WALL_OPEN_THRESHOLD = 4.0` ➔ Критический порог (в метрах) фиксации разлета стен для автоматического переключения системы в режим защиты от края платформы.
* `V2_OBSTACLE_TRACK_SEARCH_WIDTH_CLOSED = 1.35` ➔ Зажатая ширина поиска рельс на открытом пространстве (чистая колея), отсекающая конструкции станции.
* `DBSCAN_OBSTACLE_MIN_SAMPLES = 4` ➔ Ультра-чувствительный ИИ-порог кластеризации, позволяющий обнаруживать мелкие преграды на экстремальных дистанциях всего по 4 лазерным точкам.
